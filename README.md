## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors bundled together with a universal loader called xcutorsLoader, designed for Windows desktop users.

### Which executors are included in the package?

The package includes Volt, Synapse Z, Potassium, Wave, and the universal xcutorsLoader that provides unified access to all of them.

### Is XCutors free to use?

Yes, the xcutorsLoader and all included executors are free to download and use. Always download from the official repository to ensure authenticity.

### What operating systems are supported?

XCutors currently supports Windows 10 and Windows 11 (64-bit editions). macOS and Linux are not supported at this time.

### How do I update the executors?

The xcutorsLoader includes built-in auto-update functionality that checks for new versions on launch. You can also manually download the latest release from the GitHub Releases page.

### Can I use my own custom Lua scripts?

Absolutely. You can paste scripts directly into the editor, load them from local .lua or .txt files, or select pre-made scripts from the built-in script hub.

### Why is my anticomponent flagging the download?

Some anticomponent engines may classify script executors as potentially unwanted programs (PUPs) due to their injection behavior. You can add an exclusion for the XCutors folder if you trust the source. Always verify you downloaded from the official repository.

### Where can I find scripts to use with XCutors?

The built-in script hub includes a curated selection of popular community scripts. You can also find scripts shared by the community on Roblox scripting forums and Discord servers.

### The executor is not injecting — what should I do?

Make sure Roblox is fully launched and you are in a game before clicking Inject. Run the loader as administrator, temporarily disable your anticomponent, and ensure you have the latest version of XCutors installed.
